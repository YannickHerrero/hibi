**Hibi** (日々, "day by day") is a self-hosted spaced-repetition system inspired by Anki and WaniKani, designed primarily for Japanese sentence mining.

## What lives here

- Conceptual docs (how Hibi works, the FSRS scheduler, the sentence-mining workflow)
- Hand-written guides for the [`hibi-client`](https://www.npmjs.com/package/hibi-client) TypeScript SDK

The auto-generated **API reference** lives at [api.hibi.app/docs](https://api.hibi.app/docs).
